# Domain invariants

Rules the code must keep. Each has a test; change the test and this file together.

| Invariant | Why | Enforced by |
|---|---|---|
| Originals are never written. Results live in a temp file until the user saves them. Save dialogs refuse all session inputs, including aliases and macOS case variants. | Users must be able to trust the tool with their only copy. | `file_registry.rs` → save-target tests for removed inputs, symbolic/hard links and case variants; `results.rs` (store + atomic copy) |
| A result is never larger than its input; otherwise the output is the original, byte for byte (`keptOriginal`). | "Compress" must never make a file worse. | `crates/fileforge-core/tests/pdf_compress.rs` → `output_is_never_larger…`, `corrupted_files_never_panic_and_never_grow` |
| Lossless keeps decoded content identical: page content streams and image bytes are unchanged. | ADR-0003: lossless means lossless. | `lossless_shrinks_structure_and_keeps_every_byte_of_content` |
| Encrypted PDFs are refused, including owner-password-only files that open without a password. | Rewriting would silently drop the protection. | `encrypted_pdfs_are_refused_even_without_a_user_password` |
| Digitally signed PDFs are refused. | Any rewrite invalidates the signature. | `signed_pdfs_are_refused` |
| PDF/A-1 files keep a classic cross-reference table and readable XMP. | PDF/A-1 forbids object and cross-reference streams. | `pdfa1_files_keep_a_classic_cross_reference_table` |
| Images are downsampled only from placements found on pages, to the densest axis, and only when >15% over the target DPI. | Never make a visible image blurrier than requested. | `images.rs` unit tests, `balanced_downsamples…`, `placement_inside_form_xobjects…`, `images_drawn_nowhere…` |
| Flate-to-JPEG conversion requires explicit `compressFlatePhotos`, a validated gray/RGB image passing the source-pixel screen-content veto, and at least 20% savings against both the source stream and equivalent Deflate. Detected screen content keeps Deflate; classification cannot prove image origin (ADR-0016). | Avoid unnecessary loss of lossless photo pixels and JPEG artifacts on detected UI/text; DPI downsampling remains a separate preset behavior. | `tests/pdf_flate_photos.rs`, `pdf::images` gain/limit tests, `pdf::photos` edge tests |
| Metadata, thumbnails and editing data are removed only on request and never change page content. Files declaring PDF/A, PDF/UA, PDF/X, PDF/E or PDF/VT keep their catalog XMP and Info. The structure tree is never removed. | Privacy and size must not cost a standard claim or accessibility (ADR-0012). | `crates/fileforge-core/tests/pdf_metadata.rs` |
| Unsupported image encodings (CMYK, Lab, Indexed, 16-bit, masks, color-key masks, JBIG2) are left byte-identical. | Better no gain than a corrupted color. | `unsupported_color_spaces_are_left_byte_identical` |
| JPEG 2000 becomes JPEG only for 8-bit gray/RGB images whose codestream matches the dictionary (size, channels, no alpha) and that have no `Decode` or `SMaskInData`; all others are left byte-identical. | PDF ignores `Decode` for JPEG 2000 and may take its alpha as the soft mask; converting those would change how the page looks (ADR-0015). | `jpeg2000_images_become_jpeg…`, `unusual_jpeg2000_images_are_left_byte_identical`, `pdf::jpx` unit tests |
| Images are decoded as reference decoders (libjpeg, OpenJPEG) decode them, so compressing a result again never corrupts it. | zune-jpeg 0.5.15 and hayro-jpeg2000 0.4.0 misdecoded real files (ADR-0015). | `compressing_our_own_output_again_keeps_the_pixels`, `decodes_irreversible_images_like_openjpeg` |
| Batch saving never overwrites existing files (`name (2).pdf`), even on simultaneous name collisions. | Saving into a folder must be safe without a dialog per file. | `results.rs` → `unique_paths_never_reuse_existing_names`, `concurrent_batch_saves_never_overwrite_each_other` |
